Detailed Description

Random operation mode descriptor structure.

This structure is used to store all information needed in the top level Random DRBG functions, determines which mode the DRBG shall be operated in (normal, test or patch mode) and specifies pointers to functions implementing the DRBG in the chosen operation mode.
