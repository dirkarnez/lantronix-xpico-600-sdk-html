usb_status_t USB_DevicePhdcRecv ( class_handle_t  handle,
uint8_t  ep,
uint8_t *  buffer,
uint32_t  length 
)

Receives data through a specified endpoint.

The function is used to receive data through a specified endpoint. The function calls the USB_DeviceRecvRequest internally.

Parameters
[in]handleThe PHDC class handle received from usb_device_class_config_struct_t::classHandle.
[in]epEndpoint index.
[in]bufferThe memory address to save the received data.
[in]lengthThe data length want to be received.
Return values
kStatus_USB_InvalidHandleThe device handle is not found.
kStatus_USB_BusyThe previous transfer is pending.
kStatus_USB_SuccessThe receiving is successful.
Note
The function can only be called in the same context.
