API_RESULT BT_avctp_channel_send_message ( AVCTP_HANDLE *  handle,
UCHAR *  packet,

UCHAR  channel_type 
)

To request transfer of AVCTP Control Message Packets.

Description:
This API enables application/profile to send AVCTP Control Message Packets over an AVCTP Signaling Connection.
Parameters
[in]handleThe AVCTP Handle, from which Profile Index will be used to identify the Profile Entity and Signaling Index will be used to identify AVCTP SIgnaling Channel.
[in]packetThe AVCTP Control Message Packet to transfer over the AVCTP Signaling Connection.
[in]packet_lenLength of the AVCTP Control Message Packet.
[in]channel_typeChannel Type - Command or Browsing.
Returns
API_RESULT
  • API_SUCCESS, on successful initiation of the procedure.
  • AVCTP Error Code, describing the reason for failure.
Remarks
The application should provide a complete AVCTP Control Message Packet for transmission, which includes the following:
  • Space for L2CAP Header - 4 Bytes. This will be filled by L2CAP module.
  • Space for AVCTP Control Message Packet Header - 3 Bytes. This will be filled by AVCTP module.
  • AVCTP Control Message Packet Payload.
The memory for AVCTP Control Message Packet should always be dynamically allocated, and it will be freed by the EtherMind Stack, upon successful transmission.
The Trascation Lable, Message Type, Packet Type field of the AVCTP control packet header should be updated by the application/profile. AVCTP has provided macros to update these parameters.

API_RESULT BT_avctp_profile_register ( AVCTP_EVENT_NTF_CB  ntf_cb,
UINT16  profile_id,
AVCTP_HANDLE *  handle 
)

To register a Profile with AVCTP.

Description:
This API enables application/profile to register a Profile to AVCTP. On successful registration, AVCTP allocates a Profile Entity and sets the index of Profile Entity in the AVCTP Handle provided by the application. The AVCTP Handle shall be used hereafter by the application/profile to initiate any procedure (API).
Parameters
[in]ntf_cbThe AVCTP Event Notfication Callback which AVCTP should use to report AVCTP events.
[in]profile_idProfile Identifier.
[out]handleThe AVCTP Handle in which Profile Entity index will be appropriately set, on successful registration.
Returns
API_RESULT
  • API_SUCCESS on successful initiation of the procedure.
  • AVCTP Error Code describing the reason of failure.
See also
BT_avctp_profile_deregister
