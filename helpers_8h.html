Returns
0 on success.
-1 if the output buffer is too small or the input string is not a valid hexadecimal representation.

◆ mbedtls_test_unhexify_alloc()

unsigned char* mbedtls_test_unhexify_alloc ( const char *  ibuf,
size_t *  olen 
)

Allocate and fill a buffer from hex data.

The buffer is sized exactly as needed. This allows to detect buffer overruns (including overreads) when running the test suite under valgrind.

If the size if zero, a pointer to a zeroized 1-byte buffer is returned.

For convenience, dies if allocation fails.
