Detailed Description

Lightweight abstraction layer for block ciphers with 128 bit blocks, for use by the GCM and CCM modules.

const unsigned char  input[16],
unsigned char  output[16] 
)

Encrypt one block (16 bytes) with the configured key.

Parameters
ctxThe context holding the key.
inputThe buffer holding the input block. Must be 16 bytes.
outputThe buffer to which the output block will be written. Must be writable and 16 bytes long. This must either not overlap with input, or be equal.
Return values
