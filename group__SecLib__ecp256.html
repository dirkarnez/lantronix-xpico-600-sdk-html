◆ ECDSA_SignFromHash()

secEcdsaStatus_t ECDSA_SignFromHash ( uint8_t *  pSignature,
const uint8_t *  pDigest,
uint16_t  DigestLen,
const uint8_t *  pPrivKey 
)

ECDSA signature generation.

Given a random 32 byte ephemeral key candidate k, a message digest e and a private key, this function verifies if the ephemeral key is in range [1,n-1] and generates an ECDSA signature (r,s) with

r = (k*G).x mod n s = k^(-1)*(e'+r*d) mod n

of the message digest. Here e' is derived from e by either truncating it or padding it with zeros to 32 bytes.

NOTE: The ECDSA signature generation function expects a valid private key, no private key validation is performed. An ephemeral key is generated internally

Parameters
[out]pSignaturePointer to a 64 byte buffer to where the generated signature (r,s) will be stored. The signature is stored as the concatenation r||s with the integers r and s being in BE format.
[in]pDigestPointer to a buffer of byte length digestLen containing the message digest in BE format.
[in]DigestLenByte length of the passed message digest.
[in]pPrivKeyPointer to a 32 byte buffer containing the private key d in range [1,n-1] in BE format.
Return values
gSecEcdsaSuccess_cThe operation finished successfully.
gSecEcdsaInvalidEphemeralKey_cThe passed ephemeral key is out of range.
gSecEcdsaFailure_cThe signature generation failed and shall be repeated with a fresh ephemeral key.

◆ ECDSA_VerifySignature()

secEcdsaStatus_t ECDSA_VerifySignature ( const uint8_t *  pPubKey,
const uint8_t *  pDigest,
uint16_t  DigestLen,
const uint8_t *  pSignature 
)

ECDSA signature verification.

This function verifies an ECDSA signature of a message digest e by verifying the equation

(u1*G + u2*Q).x mod n = r

where u1 = e'*s^(-1) mod n and u2 = r*s^(-1) mod n. Here, Q is a valid public key and e' is derived from e by either truncating it or padding it with zeros to 32 bytes.

Parameters
[in]pPubKeyPointer to a 64 byte buffer containing the public key (x,y). The public key is stored as the concatenation x||y with x and y being in BE format.
[in]pDigestPointer to a buffer of byte length digestLen containing the message digest in BE format.
[in]DigestLenByte length of the passed message digest.
[in]pSignaturePointer to a 64 byte buffer containing the generated signature (r,s). The signature is stored as the concatenation r||s with the integers r and s being in BE format.
Return values
gSecEcdsaSuccess_cThe operation finished successfully.
gSecEcdsaInvalidSignature_cThe passed signature is invalid.
gSecEcdsaInvalidPoint_cThe passed public key is invalid.

◆ ECP256_DoublePointMulAdd()

secEcp256Status_t ECP256_DoublePointMulAdd ( void *  ec_R,
const void *  ec_P1,
const void *  ec_fe1,
const void *  ec_P2,
const void *  ec_fe2 
)

Load coordinate forcing it to belong to field.

This function performs a double scalar multiplication ec_R = ec_fe1*ec_P1 + ec_fe2*ec_P2 for scalars ec_fe1,ec_fe2 in range [1,n-1] and affine points P1 and P2. For double scalar multiplications of the form k1*G + k2*P2, i.e. with the first point being the base point G, one can alternatively leave P1 unspecified (see below) in which case a performance improved algorithm will be used for the operation.

Parameters
[out]ec_RPointer to 16 CPU words buffer to where the scalar multiplication result shall be stored in affine coordinates in BE format in range [0,p-1].
[in]ec_P1Pointer to a 64 byte buffer containing the point P1 = (x1,y1). The point is stored as the concatenation x1||y1 with x1 and y1 being in BE format. If NULL is passed for pPoint1, then the function will take ec_P1 = G.
[in]ec_P2Pointer to a 64 byte buffer containing the point P2 = (x2,y2). The point is stored as the concatenation x2||y2 with x2 and y2 being in BE format.
[in]ec_fe1Pointer to 8 CPU words buffer containing the scalar in range [1,n-1] in BE format.
[in]ec_fe2Pointer to 8 CPU words buffer containing the scalar in range [1,n-1] in BE format.
Returns
gSecEcp256Success_c if success
