Detailed Description

ELS header for elliptic curve cryptography This header exposes functions that enable using the ELS for elliptic curve cryptography. All functions operate on the NIST P-256 curve. The ECC operations supported are:

  • ECC key generation
  • ECC Diffie-Hellman key exchange
  • ECDSA signature generation/verification
