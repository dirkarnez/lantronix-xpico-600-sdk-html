◆ ATT_MAX_MTU

#define ATT_MAX_MTU   1024U

ATT_MAX_MTU

Maximum MTU supported by ATT on an Instance. ATT Specification mandates the minimum MTU as 23. Hence the default value used would be 23.

This size is inclusive of the 1 byte ATT Opcode, 2 bytes ATT Handle, and the value following it.

Minimum Value: 23 Maximum Value: L2CAP_MAX_MTU for Classic Link. As per requirement for LE Link
