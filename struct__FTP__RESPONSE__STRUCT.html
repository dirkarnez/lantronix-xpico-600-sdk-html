Detailed Description

Data type to specify the FTP response parameters.

Description:
This structure contains the response parameters filled by the application or the profile depending on the role.

At FTP server, this structure shall be filled by the application to send the response for the recently received request and at FTP client, this structure will be filled by the profile to notify the application of the response indication for the previously sent request.

Note
Typically, obj_size is set to size of file during file pull operation, otherwise set this parameter to Zero.
