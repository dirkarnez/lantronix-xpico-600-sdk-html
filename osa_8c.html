◆ OSA_RWLockReadLock()

int OSA_RWLockReadLock ( osa_rw_lock_t *  lock,
unsigned int  wait_time 
)

Acquire reader lock

This function acquires a reader lock. While readers can acquire the lock on a sharing basis, writers acquire the lock in an exclusive manner.

Parameters
[in]lockpointer to the reader-writer lock handle
[in]wait_timeThe maximum amount of time, in OS ticks, the task should block waiting for the lock to be acquired. The special values osaWaitForever_c and osaWaitNone_c are provided to respectively wait infinitely or return immediately.
Returns
WM_SUCCESS on success
-WM_FAIL on error
