Driver Change Log

PHYCH182F7

The current PHYCH182F7 driver version is 1.0.0.

  • 1.0.0
    • Initial version for WCH CH182F7 (7-pin RMII package) Ethernet PHY transceiver.
    • Supports 10/100Mbps RMII interface only.
    • Paged register architecture support (BASE PAGE and PAGE 7).
    • Link change interrupt support (following WCH official implementation).
    • Speed/duplex detection from PHY_BASICCONTROL_REG (CH182F7-specific).
    • Interrupt clear via PAGE 0 Reg 0x1E read operation.
