Detailed Description

PD unstructured vdm command parameter.

It is used in PD_Command for PD_DPM_SEND_UNSTRUCTURED_VDM and in callback for PD_DPM_UNSTRUCTURED_VDM_RECEIVED. For PD_DPM_SEND_UNSTRUCTURED_VDM: it provide vdm command information to PD stack, PD stack will start the command with the information. For PD_DPM_UNSTRUCTURED_VDM_RECEIVED: it provide information for the received unstructured vdm to APP.
