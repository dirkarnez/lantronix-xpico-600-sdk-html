To check for security requirement.

Description:
This internal platform API is used to assert for required security for a link during SMP authentication procedure.
Parameters
[in]auth_reqRequired Authentication, as per auth_req format in spec
[in]auth_possPossible Authentication, as per auth_req format in spec
[in]assocIOCAP Association model possible
Returns
API_SUCCESS if requirement met, API_FAILURE if requirement failed to meet
Note
Currently, implementation does checking only for MITM

◆ smp_purge_device_list_pl()

API_RESULT smp_purge_device_list_pl ( UCHAR *  free_index)

To purge internal device list.

Description:
This internal platform API is used to purge and manage the internal device list. This API is called when SMP device database is full and there is no space to add new device.
Parameters
[out]free_indexIndex of freed device in database
Returns
API_RESULT:
  • API_SUCCESS: If successful.
  • Error Codes: An error code describing the cause of failure.
