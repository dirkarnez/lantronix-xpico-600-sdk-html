Macro Definition Documentation

◆ L2CA_IS_DATA_WRITE_SUCCESS

#define L2CA_IS_DATA_WRITE_SUCCESS (   ret)
Value:
((API_SUCCESS != (ret)) && \
(L2CAP_TX_FLOW_OFF != (ret)) && \
(L2CAP_FEC_TX_WINDOW_FULL != (ret)))? (ret): (API_SUCCESS)

Check if L2CA Data Write API returned success. This macro takes in the actual retval from the API and evaluates based on whether the retval is any of the flow control error codes that eventually mean a success.

It's not really a failure, but a warning that next write on this L2CAP CID will fail, and the flow is off till L2CA_TxFlowIND indicates flow on again.
