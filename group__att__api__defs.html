API to send Error Response.

Note: Though the following definition are MACROs, they are to be treated like APIs

Description:
This routine sends Error Response to peer device.
Parameters
[in]handleIdentifies the remote ATT entity to which Error Response is to be sent
[in]paramIdentifies the op code for which error response is sent, handle resulting in error and the reason for error. See ATT_ERROR_RSP_PARAM.
Returns
API_SUCCESS or an error code indicating reason for failure.
