int mbedtls_ecp_setupDomainParams ( mbedtls_ecp_group *  grp,
mcuxClEcc_DomainParam_t *  pDomainParams 
)

This function sets up the domain parameters to be used in the mcuxCl implementation, which requires big-endian input parameters (the endianess of parameters is inverted).

Parameters
grpThe ECP group to use. This must be initialized and have domain parameters loaded, for example through mbedtls_ecp_load() or mbedtls_ecp_tls_read_group().
pDomainParamsStructure to hold the domain parameters in suitable format for the mcuxCl implementation.The buffers for the parameters must be alocated before this function is called.
