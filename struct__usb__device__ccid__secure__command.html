Detailed Description

Secures the command structure of the command message in the bulk-out pipe.

This is a command message to allow entering the PIN for verification or modification.

The response to this command message is the RDR_to_PC_DataBlock response message.

The value depends of wLevelParameters. When wLevelParameters is 0000h or 0001h abData = abPINOperationDataStructure. For other values of wLevelParameters this field is the continuation of the previously sent PC_to_RDR_Secure.
