Detailed Description

Simple workqueue implementation. A workqueue is an object that uses a dedicated thread to process work items in a FIFO manner.

int WORKQ_Start ( fwk_workq_t *  queue,
const osa_task_def_t *  thread_def 
)

Initializes a work queue and starts its thread.

This function should not be called twice for the same queue.

Parameters
[in]queuepointer to the queue.
[in]thread_defpointer to the thread definition provided by FWK_WORKQ_THREAD.
Returns
int 0 if success
int 1 if the queue was already started (no change done)
int -EINVAL if incorrect parameters.
int -ENOMEM if memory allocation failed.
