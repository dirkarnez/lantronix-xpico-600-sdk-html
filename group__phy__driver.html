◆ phy_ch182f7_resource_t

typedef struct _phy_ch182f7_resource phy_ch182f7_resource_t

PHY resource structure for CH182F7 variant.

This structure contains the MDIO read/write function pointers required for communicating with the CH182F7 PHY via RMII interface.

Note
CH182F7 uses paged register architecture. Access to extended registers requires switching pages via PHY_PAGE_SEL_REG (0x1F).

◆ PHY_CH182F7_EnableLinkInterrupt()

status_t PHY_CH182F7_EnableLinkInterrupt ( phy_handle_t *  handle,
phy_interrupt_type_t  type 
)

Enables/Disables PHY link change interrupt.

This function controls link status change interrupt for CH182F7.

CH182F7 hardware supports multiple interrupt types in Reg0x13:

  • bit 14: Speed change
  • bit 13: Link change (ENABLED by this function)
  • bit 12: Duplex change
  • bit 2: Auto-negotiation complete

WCH recommends enabling ONLY link change interrupt to avoid unnecessary interrupt events. When link changes, software should re-read all PHY status registers to get complete information.

Note
Interrupt control is on PAGE 7 register 0x13. Interrupt polarity is configured via bit 9 (0=Low active, 1=High active). After enabling interrupt, clear pending status by calling PHY_CH182F7_ClearInterrupt().
Parameters
handlePHY device handle.
typePHY interrupt type:
  • kPHY_IntrActiveLow: Enable interrupt with low active (falling edge)
  • kPHY_IntrActiveHigh: Enable interrupt with high active (rising edge)
  • kPHY_IntrDisable: Disable link change interrupt
Return values
kStatus_SuccessPHY interrupt configuration success
kStatus_TimeoutPHY MDIO visit timeout

Gets the PHY link speed and duplex.

This function gets the speed and duplex mode of PHY. User can provide one of speed or duplex address parameter and set the other as NULL if only one is needed.

Note
After auto-negotiation completes, the speed and duplex values in the Basic Control Register (0x00) reflect the negotiated link parameters.

  • Software reset
