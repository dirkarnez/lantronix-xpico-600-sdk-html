◆ wt_exit_pl

wt_exit_pl ( )    0
Description
This function is called by the Write Task Start Routine (write_task_start_routine) to know if the Task needs to break out of its core loop and return (which effectively means exit of the task).
Parameters
None
Returns
UCHAR 0 - No exit, continue to execute. 1 - Break from core loop & return.
