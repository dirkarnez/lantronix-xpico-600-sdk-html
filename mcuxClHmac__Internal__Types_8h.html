◆ mcuxClHmac_AlgorithmDescriptor_t

typedef struct mcuxClHMac_AlgorithmDescriptor mcuxClHmac_AlgorithmDescriptor_t

HMAC structure.

This internal structure provides all implementation details for the top level mcuxClHmac functions. It consists of Init, Update, Finalize and Oneshot engines and the output size.

◆ mcuxClHmac_Context_Els_t

typedef struct mcuxClHmac_Context_Els mcuxClHmac_Context_Els_t

HMAC context structure for modes using ELS HW.

This structure captures all the information that the Mac interface needs to know for a particular HMAC mode/algorithm to work. It also contains information specific to the ELS HW implementation of HMAC.
