◆ ELS_PowerDownWakeupInit()

status_t ELS_PowerDownWakeupInit ( ELS_Type *  base)

ELS Init after power down.

This function enable all ELS related clocks, enable ELS and start ELS PRNG. Normally all of these actions are done automatically by boot ROM, but if an application uses Power Down mode this function must be called before using ELS after wake-up.

Returns
kStatus_Success upon success, kStatus_Fail otherwise
