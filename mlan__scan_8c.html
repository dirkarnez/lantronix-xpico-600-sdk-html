◆ wlan_abort_split_scan()

void wlan_abort_split_scan ( void  )

Abort the split scan if it is in progress.

After this call returns this scan function will abort the current split scan and return back to the caller. The scan list may be incomplete at this moment. There are no other side effects on the scan function apart from this. The next call to scan function should proceed as normal.

◆ wlan_cmd_802_11_scan()

mlan_status wlan_cmd_802_11_scan ( IN mlan_private *  pmpriv,
IN HostCmd_DS_COMMAND *  pcmd,
IN t_void *  pdata_buf 
)

Prepare a scan command to be sent to the firmware.

Use the wlan_scan_cmd_config sent to the command processing module in the wlan_prepare_cmd to configure a HostCmd_DS_802_11_SCAN command struct to send to firmware.

The fixed fields specifying the BSS type and BSSID filters as well as a variable number/length of TLVs are sent in the command to firmware.

Parameters
pmprivA pointer to mlan_private structure
pcmdA pointer to HostCmd_DS_COMMAND structure to be sent to firmware with the HostCmd_DS_801_11_SCAN structure
pdata_bufVoid pointer cast of a wlan_scan_cmd_config struct used to set the fields/TLVs for the command sent to firmware
Returns
MLAN_STATUS_SUCCESS

◆ wlan_ret_802_11_scan()

mlan_status wlan_ret_802_11_scan ( IN mlan_private *  pmpriv,
IN HostCmd_DS_COMMAND *  resp,
IN t_void *  pioctl_buf 
)

This function handles the command response of scan.

The response buffer for the scan command has the following memory layout:

.----------------------------------------------------------—. | Header (4 * sizeof(t_u16)): Standard command response hdr | .----------------------------------------------------------—. | BufSize (t_u16) : sizeof the BSS Description data | .----------------------------------------------------------—. | NumOfSet (t_u8) : Number of BSS Descs returned | .----------------------------------------------------------—. | BSSDescription data (variable, size given in BufSize) | .----------------------------------------------------------—. | TLV data (variable, size calculated using Header->Size, | | BufSize and sizeof the fixed fields above) | .----------------------------------------------------------—.

Parameters
pmprivA pointer to mlan_private structure
respA pointer to HostCmd_DS_COMMAND
pioctl_bufA pointer to mlan_ioctl_req structure
Returns
MLAN_STATUS_SUCCESS or MLAN_STATUS_FAILURE

◆ wlan_scan_process_results()

void wlan_scan_process_results ( IN mlan_private *  pmpriv)

Post process the scan table after a new scan command has completed.

Inspect each entry of the scan table and try to find an entry that matches our current associated/joined network from the scan. If one is found, update the stored copy of the BSSDescriptor for our current network.

Debug dump the current scan table contents if compiled accordingly.
