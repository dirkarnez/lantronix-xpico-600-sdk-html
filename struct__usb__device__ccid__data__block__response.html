Detailed Description

Data block response structure to respond a command message in the bulk-in pipe.

The device in response to the following command messages: "PC_to_RDR_IccPowerOn", "PC_to_RDR_Secure" and "PC_to_RDR_XfrBlock" sends this response message. For "PC_to_RDR_IccPowerOn" this response message is the answer to reset (ATR) data associated with the ICC power on. In other use cases, the response message has the following format: the response data contains the optional data returned by the ICC, followed by the 2U byte-size status words SW1-SW2.
