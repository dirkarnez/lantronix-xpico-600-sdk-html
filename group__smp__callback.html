typedef API_RESULT(* SMP_UI_NOTIFY_CB) ( SMP_BD_HANDLE *bd_handle, UCHAR event_type, UINT16 event_result, void *event_data, UINT16 event_datalen) DECL_REENTRANT

SMP User Interface Notification Callback. Security Manager Protocol calls the registered callback to indicate events occurred.

Parameters
[in]bd_handlePointer to peer device handle as in SMP_BD_HANDLE
[in]event_typeAny of the Event occurred from the list at Events.
[in]event_resultAPI_SUCCESS or an error code in Error Codes or any other internal error code from the stack.
[in]event_dataData associated with the event if any or NULL.
[in]event_datalenSize of the event data. 0 if event data is NULL.
