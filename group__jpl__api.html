To add incoming SBC frames for Jitter Protection.

To add incoming SBC frames for Jitter Protection

Description
This function adds incoming SBC frames, and decodes the same to PCM if required, to Jitter Protection Buffer.
Parameters
[in]seqThe sequence number of the packet containing SBC
[in]timestampThe timestamp of the media packet containing SBC
[in]dataPointer to SBC frames that are to be added to JPL Buffer
[in]datalenThe total length of all the frames, inclusive of 1 octet SBC header
Returns
API_RESULT API_SUCCESS, or, an Error Code from BT_error.h
