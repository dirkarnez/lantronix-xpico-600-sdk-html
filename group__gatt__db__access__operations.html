Detailed Description

These abstract access functions for attributes, including read, write, prepare. The direction of update is also included as this decides checking needed security for peer and if values are editable by the peer. Please also note the 'Update' access which is used for local updates of values based on GATT_DB_HANDLE as against Attribute Handle.
