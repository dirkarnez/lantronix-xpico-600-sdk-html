MCUX_CSSL_FP_PROTECTED_TYPE ( void  )

Perform EdDSA encoding of a twisted Edwards curve point.

Parameters
[in]encodedLenLength of encoded point
Precondition
  • ECC_COORD00 and ECC_COORD01 must contain the affine coordinates of the point to encode
  • encodedLen must be the length of the buffer at ECC_COORD02
  • PS2 (OP)LEN must be set to encodedLenPkc
Postcondition
  • buffer at ECC_COORD02 contains the encoded data
