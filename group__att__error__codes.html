Detailed Description

This section describes the defines for ATT protocol specified error codes for ATT Error Response PDU

Macro Definition Documentation

◆ ATT_ATTRIBUTE_NOT_FOUND

#define ATT_ATTRIBUTE_NOT_FOUND   0x0AU

Attribute not found error is used when the ATT server cannot find any handles that belong to the Attribute type in the given range of handles that the client specified in its request. This error code can be sent to the client in response to the following request PDUs - Find Information, Find by Type Value, Read by Type, Read by Group Type requests.

◆ ATT_ATTRIBUTE_NOT_LONG

#define ATT_ATTRIBUTE_NOT_LONG   0x0BU

Attribute Not Long error code is used when the client tries to read or write a Attribute handle's value which cannot be read or written through Read Blob or multiple prepare write requests.

◆ ATT_CCD_IMPROPERLY_CONFIGURED

#define ATT_CCD_IMPROPERLY_CONFIGURED   0xFDU

Client Characteristic Configuration Descriptor Improperly Configured error code is used when a Client Characteristic Configuration descriptor is not configured according to the requirements of the profile or service.

◆ ATT_DB_OUT_OF_SYNC

#define ATT_DB_OUT_OF_SYNC   0x12U

Database Out of Sync error code is used when the ATT server has updated/changed or modified its Attribute Database which the Peer Client is unaware of.

◆ ATT_INSUFFICIENT_AUTHENTICATION

#define ATT_INSUFFICIENT_AUTHENTICATION   0x05U

Insufficient Authentication error code is used in the case when an access to a handle is attempted on a un-authenticated link but the attribute requires that the link be authenticated before any client can access it.

◆ ATT_INSUFFICIENT_AUTHORIZATION

#define ATT_INSUFFICIENT_AUTHORIZATION   0x08U

Insufficient Authorization error code is used in the case when the ATT server does not Authorize the client and hence prohibiting the client from reading the handle value.

◆ ATT_INSUFFICIENT_ENC_KEY_SIZE

#define ATT_INSUFFICIENT_ENC_KEY_SIZE   0x0CU

Insufficient encryption key size error code is used when the client tries to access an Attribute Handle's Value for which the link need to be encrypted with a key of certain minimum key size and the current link is encrypted with a key of lesser size than the minimum required.

◆ ATT_INSUFFICIENT_ENCRYPTION

#define ATT_INSUFFICIENT_ENCRYPTION   0x0FU

Insufficient encryption error code is used when the client tries to read or write an Attribute handle which requires the link to be encrypted and the link is currently not encrypted.

◆ ATT_INSUFFICIENT_RESOURCES

#define ATT_INSUFFICIENT_RESOURCES   0x11U

Insufficient Resources error code is used when the ATT server does not have enough resources such as memory etc. to process the request from the client.

◆ ATT_INVALID_ATTRIBUTE_LEN

#define ATT_INVALID_ATTRIBUTE_LEN   0x0DU

Invalid Attribute length error code is used when the Attribute value's length is not correct to process the request containing the value.

◆ ATT_INVALID_HANDLE

#define ATT_INVALID_HANDLE   0x01U

Invalid Handle error code is used in the case when the ATT handle in the ATT request PDU is invalid.

◆ ATT_INVALID_OFFSET

#define ATT_INVALID_OFFSET   0x07U

Invalid Offset error code is used in the case when the offset sent by the client in the Read blob/Prepare Write Request is invalid with respect to the length of the value in the server.

◆ ATT_INVALID_PDU

#define ATT_INVALID_PDU   0x04U

Invalid PDU error code is used in the case when the format of the PDU sent from the ATT Client is incorrect.

◆ ATT_OUT_OF_RANGE

#define ATT_OUT_OF_RANGE   0xFFU

Out of Range error code is used when an attribute value is out of range as defined by a profile or service specification.

◆ ATT_PARAM_VAL_NOT_ALLOWED

#define ATT_PARAM_VAL_NOT_ALLOWED   0x13U

Attribute parameter value not allowed error code is used when the ATT client attempts to set an attribute value that is not allowed in the current circumstances.

◆ ATT_PREPARE_WRITE_QUEUE_FULL

#define ATT_PREPARE_WRITE_QUEUE_FULL   0x09U

Write queue full error code is used when there is no more space left in the prepare write queue on the server to entertain any more prepare writes from a client.

◆ ATT_PROCEDURE_ALREADY_IN_PROGRESS

#define ATT_PROCEDURE_ALREADY_IN_PROGRESS   0xFEU

Procedure Already in Progress error code is used when a profile or service request cannot be serviced because an operation that has been previously triggered is still in progress.

◆ ATT_READ_NOT_PERMITTED

#define ATT_READ_NOT_PERMITTED   0x02U

Read Not Permitted error code is used in the case when the permission to read the value of an ATT handle is not permitted on the ATT server.

◆ ATT_REQUEST_NOT_SUPPORTED

#define ATT_REQUEST_NOT_SUPPORTED   0x06U

Request not supported error code is used in the case when the server does not support the processing of an ATT request sent from the client.

◆ ATT_UNLIKELY_ERROR

#define ATT_UNLIKELY_ERROR   0x0EU

Unlikely error is used when the processing of the Attribute request has encountered an error that is not covered by any other error code.

◆ ATT_UNSUPPORTED_GROUP_TYPE

#define ATT_UNSUPPORTED_GROUP_TYPE   0x10U

Unsupported Group Type error code is used when the Attribute type requested in the Read by Group Type request is not a valid grouping attribute on the server.

◆ ATT_WRITE_NOT_PERMITTED

#define ATT_WRITE_NOT_PERMITTED   0x03U

write Not Permitted error code is used in the case when the permission to write the value of an ATT handle is not permitted on the ATT server.
