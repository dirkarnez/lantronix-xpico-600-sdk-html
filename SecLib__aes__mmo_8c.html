Detailed Description

Copyright 2021-2025 NXP

This is the Source file for the AES Matyas-Meyer-Oseas (AES-MMO) hash function. Reference: ZigBee specification, document 05-3474-21, Aug 2015, section B.6 Block-Cipher-Based Cryptographic Hash Function. If using AES 128, let's say N=128/8 i.e 16. The maximum message bit length can be 2^2N. For AES-128 2^N bits is 2^13 i,e, 8192.
