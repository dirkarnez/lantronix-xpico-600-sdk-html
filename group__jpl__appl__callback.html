JPL_CB Typedef for the Application notification callback pointer

Parameters
[in]event_typeThe JPL Event Type for which the callback is called
[in]event_dataPointer to the PCM data returned for playing out. Valid only in case of event JPL_DATA_IND
[in]event_datalenSize of PCM data, in number of octets, passed to application Valid only in case of event JPL_DATA_IND
Returns
API_RESULT API_SUCCESS, otherwise an error code describing the reason for failure
