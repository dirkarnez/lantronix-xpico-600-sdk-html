◆ AVDTP_SET_MEDIA_PACKET_HEADER

#define AVDTP_SET_MEDIA_PACKET_HEADER (   ptr,
  v,
  p,
  x,
  m,
  pt,
  ts,
  ssrc 
)

This utility macro is used to initialize a Media Packet Header with all required information - Version, Padding, Extension, Marker and Payload Type, Time Stamp and Synchronization Source (SSRC) information. The application does not need to provide the Sequence Number, as the AVDTP fills up the Sequence Number field internally. Also, this version of AVDTP implementation does not support transmission of Contributing Source (CSRC) information. Hence, the "CSRC Count (CC)" field is set to zero.

Parameters
[in,out]ptrPointer to the buffer location for the Media Packet Header
[in]vVersion of the RTP implementation
[in]pPadding Bit (see AVDTP Specification v1.0, section 7.2.1)
[in]xExtension Bit (see AVDTP Specification v1.0, section 7.2.1)
[in]mMarker Bit (see AVDTP Specification v1.0, section 7.2.1)
[in]ptPayload Type (see AVDTP Specification v1.0, section 7.2.1)
[in]tsTime Stamp (see AVDTP Specification v1.0, section 7.2.1)
[in]ssrcThe SSRC (see AVDTP Specification v1.0, section 7.2.1)

◆ AVDTP_SET_SEP_CAPABILITY

#define AVDTP_SET_SEP_CAPABILITY (   sep_cap,
  s_t,
  m_t,
  c_t,
  ie_l,
  ie 
)

This utility macro is used to initialize Codec Parameters of the SEP Capability Structure (AVDTP_SEP_CAP).

Parameters
[in]sep_capAVDTP SEP Capability Structure.
[in]s_tAVDTP Stream End Point Type.
[in]m_tAVDTP Media Type.
[in]c_tAVDTP Media Codec Type - SBC/MPEG/ATRAC etc.
[in]ie_lLength of the Codec Capabilities information Element.
[in]ieBuffer containing Codec Capabilities Information Element.
Stream End Point Type
Stream End Point Type should be selected from one of constants given below:
  • AVDTP_SEP_SOURCE
  • AVDTP_SEP_SINK
Media Type
Media Type should be selected from one of constants give below:
  • AVDTP_MEDIA_AUDIO
  • AVDTP_MEDIA_VIDEO
  • AVDTP_MEDIA_MULTIMEDIA
Media Codec Type
Media Codec Type should be selected from one of constants give below:
  • AVDTP_CODEC_AUDIO_SBC
  • AVDTP_CODEC_AUDIO_MPEG_1_2
  • AVDTP_CODEC_AUDIO_MPEG_2_4
  • AVDTP_CODEC_AUDIO_ATRAC
See also
AVDTP Media Types, AVDTP Stream End Point Types, AVDTP Media Codec Types
