◆ BT_obex_extract_obex_headers()

API_RESULT BT_obex_extract_obex_headers ( UCHAR *  data,
UINT16  datalen,
OBEX_OBJ_HEADER *  hdr,
UCHAR *  header_num 
)

Utility to extract headers and related data from a given received OBEX message.

Description:
This API extracts OBEX headers and its related data from the data stream that is passed by the profile/application. It fills up obj_hdr with the extracted OBEX headers.
Parameters
[in]dataThe OBEX data stream to be parsed.
[in]datalenThe total length of the data stream left to be parsed. It can be used to ensure that the length of the received data as parsed from the data stream is less than or equal to, the total length of the packet.
[out]hdrStructure into which the parsed data is filled in.
[out]header_numNumber of OBEX headers extracted.
Returns
API_RESULT Always returns API_SUCCESS. Caller has to ensure that pointer 'hdr' point to array of OBEX header and also need to use the extracted number of OBEX headers 'header_num'.

◆ BT_obex_get_connect_flag()

API_RESULT BT_obex_get_connect_flag ( OBEX_HANDLE *  obex_handle,
UCHAR *  connect_flag 
)

Utility to extract the OBEX connect flags.

Description:
This API is used to extract the connect flags in the OBEX connect request or OBEX connect response.
Parameters
[in]obex_handleHandle to refer the OBEX instance.
[out]connect_flag8-bit connect flags.
Returns
API_RESULT API_SUCCESS on success otherwise an error code describing the reason for failure
Note
All connect request flags except bit 0 are currently reserved and are set to zero, and shall be ignored by the receiving side. All connect response flags are also set to zero and shall be ignored at the receiving side.

API_RESULT BT_obex_get_next_header ( UCHAR *  data_stream,
UINT16  data_length,
UINT16 *  length_parsed,
OBEX_OBJ_HEADER *  obj_hdr 
)

Utility to extract the OBEX header and related data from a given OBEX received message.

Description:
This API extracts the OBEX header and its related data from the data stream that is passed by the profile/application layer. This function is called repeatedly to parse the string of headers and related data received in a data stream.
Parameters
[in]data_streamThe data stream to be parsed.
[in]data_lengthThe total length of the data stream left to be parsed.
[out]length_parsedThe length of the headers and data that is parsed is returned in this argument. This can be used in the following invocation of the function to offset the data pointer forward by 'length_parsed' length.
[out]obj_hdrStructure into which the parsed data is filled in.
Returns
API_RESULT API_SUCCESS on success otherwise an error code describing the reason for failure
Note
None

◆ BT_obex_get_setpath_flag()

API_RESULT BT_obex_get_setpath_flag ( OBEX_HANDLE *  obex_handle,
UCHAR *  setpath_flag 
)

Utility to extract the OBEX setpath flags.

Description:
This API is used to extract the OBEX setpath flags of latest setpath request.
Parameters
[in]obex_handleHandle to refer the OBEX server instance.
[out]setpath_flag8-bit setpath flags.
Returns
API_RESULT API_SUCCESS on success otherwise an error code describing the reason for failure
Note
The valid flags are only the first two bits of the setpath_flag is valid. Bit 0: Backup a level before applying the name (equivalent to ../ on many systems) Bit 1: Don't create folder if it does not exist, instead return an Error
