◆ BT_mcap_register_mep()

API_RESULT BT_mcap_register_mep ( MCAP_MEP *  mep,
UCHAR *  mep_id 
)

To register application Exchange Point with MCAP.

This routine enables MCAP applications/profiles an exchange point with MCAP in order to receive asynchronous events from MCAP. The profile or application is also expected to provide the PSM values to be used for control channel and data channel PSM, to facilitate creation of control channel and subsequently data channels for it.

Parameters
[in]mepMCAP Exchange point info to be provided by the MCAP application or profile in order to start receiving MCAP events.
[out]mep_idUnique MCAP Exchange Point identifier provided by MCAP. This is identifier is to be provided by the application during subsequent creation of control channel connection
Returns
API_RESULT: API_SUCCESS or an error code indicating reason for failure
