Detailed Description

Events Notified on receiving PDUs from Peer, or on Request Timeouts or Generated Locally.

Most of these events are associated with ATT PDUs which are defined in ATT specification section 'ATTRIBUTE PROTOCL PDUS'. The parameters associated with these events are the same as defined in the referred ATT section.

For the locally generated events, the associated parameters are described along with the event.

In the ATT Callback Application Callback, ATT PDU Event is provided as 'att_event' and associated parameter in octet stream as 'data_param'.
