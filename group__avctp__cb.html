AVCTP_EVENT_NTF_CB

AVCTP Event Notification Callback.

This data type represents the AVCTP Event Notification Callback, which AVCTP uses for the following purposes:

  • To confirm result of an operation initiated by the upper layer application/profile.
  • To inform upper layer application/profile of the events - for example, disconnection of the AVCTP connection, or, reception of AVCTP control messages.
Parameters
[in]event_typeThis parameter defines the AVCTP event being reported. The valid values for this parameter are defined in "AVCTP Event Notification Callback Event Types" section.
[in]event_resultIf the event being reported is a result of an earlier trigger (an AVCTP API) by the application, this parameter holds the result of the procedure. On successful completion of the procedure this parameter will have a value of 0x0000 (API_SUCCESS), else it will contain an Error Code describing the reason for failure. For asynchronous event indications (e.g. AVCTP_CONNECT_IND), this parameter holds the possible reason due to which the event is being reported.
[in]avctp_handleThis parameter is a pointer to AVCTP_HANDLE describing the application/profile responsible for this event.
[in]event_dataDepending upon the event_type, this parameters holds any data being given to the AVCTP application. Description of any such data will be provided whenever appropriate in the description of AVCTP APIs that follows.
[in]event_datalenThis parameter specifies the size of event_data above.
Returns
API_RESULT
  • API_SUCCESS on successful initiation of the procedure.
  • AVCTP Error Code describing the reason of failure.
