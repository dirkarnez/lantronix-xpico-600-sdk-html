API_RESULT BT_dbase_activate_record ( UINT32  record_handle)

To activate an SDP Database Service Record.

Description:
This API activates a given SDP Service Record in the SDP Database. Once activated, the Service is now discoverable by other remote Bluetooth devices (SDP client devices).
Parameters
[in]record_handleIdentifies the Service Record in SDP Database.
Returns
API_SUCCESS or one of the error codes as defined in BT_error.h.

◆ BT_dbase_change_attr_value()

API_RESULT BT_dbase_change_attr_value ( UINT32  record_handle,
UINT16  attr_id,
UCHAR *  attr_value,
UINT16  attr_value_length 
)

To cahnge the value of an attribute in an SDP Database Record.

Description:
This API changes the attribute value of a SDP Service Record, as identified by the given record handle. This API can only be used in cases where existing attribute value needs to be changed and the size (in octets) of the new attribute value is more than the existing attribute value size.
Parameters
[in]record_handleIdentifies the SDP Database Service Record.
[in]attr_idThe Attribute ID whose value to be changed.
[in]attr_valueCaller allocated UCHAR buffer containing the octets of the new value for the specified attribute. This parameter must be resident, and should not be freed by the caller, as it will be used by the SDP Database to provide the attribute value.
[in]attr_value_lengthSize, in octets, of the buffer containing the new value.
Returns
API_SUCCESS or one of the error codes as defined in BT_error.h.
Note

◆ BT_dbase_get_rec_handles()

API_RESULT BT_dbase_get_rec_handles ( UCHAR *  uuids_array,
UCHAR  num_uuids,
UCHAR *  num_handles,
UINT32 *  handle_array 
)

To get SDDB Record Handles for an UUID search pattern.

Description:
This function provides an Interface to get the SDDB Record Handles that match a list of UUIDs which are passed as input parameters.
Parameters
[in]uuids_arraySpecifies the array of 128-bit UUIDs as the search pattern based on which the record handles are to be matched.
[in]num_uuidsNumber of UUIDs in the search pattern.
[in,out]num_handlesAs IN parameter it indicates the Maximum Number of Record Handles that can be returned (by filling in the buffer provided by the caller for this purpose). As OUT parameter it indicates the Actual Number of Records which has matched the given search pattern.
[out]handle_arrayArray of Record Handles for which match is found. Memory for this shall be allocated allocated by caller. If handle_array is NULL, the caller wants to know how many record handle matches. Caller will use the matching record handle information to allocate appropriate memory, in sub-sequent call to this API.
Returns
API_RESULT: API_SUCCESS on success otherwise an error code describing the cause of failure.

API_RESULT BT_dbase_get_record_handle ( UCHAR  service_type,
UCHAR  service_instance,
UINT32 *  rec_hdl 
)

To get the SDDB Record Handle, if present.

Description:
This API returns the SDP Record Handle from the SDP Databse that is associated with a particular service type and its instance.
Parameters
[in]service_typeIdentifies the service type (for example, for Serial Port Profile "DB_RECORD_SPP"). All the service types are defined in the "db_gen.h".
[in]service_instanceIdentifies the instance of a particular service type (for example, if Serial Port Profile has two instances, then to get the Record Handle of the first instance it should be 0 and for the next instance it should be 1).
[out]rec_hdlPointer to a caller allocated UINT32 variable where the associated SDP Record Handle will be copied on return.
Returns
API_SUCCESS or one of the error codes as defined in BT_error.h.
Note

◆ BT_dbase_get_server_channel()

API_RESULT BT_dbase_get_server_channel ( UINT32  record_handle,
UINT16  attr_id,
UCHAR *  server_channel 
)

To get a RFCOMM Server Channel present in an SDP Database Record.

Description:
This function returns the RFCOMM Server Channel corresponding to a SDP Service Record and an Attribute ID. This API is useful only in the case of profiles/application running over RFCOMM.
Parameters
[in]record_handleIdentifies the SDP Database Service Record.
[in]attr_idAttribute ID that the RFCOMM Server Channel is associated with. For most of the cases, as per the Bluetooth specification Profiles over RFCOMM, the Attribute ID needs to be the "Protocol Descriptor List". Some profile (such as, the Basic Printing Profile), more than one RFCOMM Server Channel may be used. This additional RFCOMM Server Channels, if any, are usually associated with the "Additional Protocol Descriptor List" Attribute ID.
[out]server_channelPointer to a caller allocated UCHAR variable, that is filled with the RFCOMM Server Channel value on return.
Returns
API_SUCCESS or one of the error codes as defined in BT_error.h.
Note

API_RESULT BT_dbase_get_service_class_uuids ( UCHAR *  uuid_buffer,
UINT32 *  uuid_buffer_length 
)

To extract Service Class UUIDs present in the SDDB.

Description:
This function returns the Service Class UUIDs present in all the SDP Service Records (active and inactive).
Parameters
[in]uuid_bufferCaller provided buffer, where the UUIDs to be filled.
[in,out]uuid_buffer_lengthIN: Caller indicates the legth of UUID buffer (in Octet). OUT: This function modifies the value with the number of octets filled by the UUIDs before returning. Note: The length provided by the caller should be always even.
Returns
API_RESULT: API_SUCCESS on success otherwise an error code describing the cause of failure.
  • API_SUCCESS If all the available Service Class UUIDs are filled in the provided buffer.
  • DB_NULL_PARAM_NOT_ALLOWED If the parameters are not valid.
  • DB_MORE_SERVICE_CLASS_UUIDS_AVAILABLE If the uuid buffer does not have suffitient space for all the available uuids.

API_RESULT BT_dbase_update_attr_value ( UINT32  record_handle,
UINT16  attr_id,
UCHAR *  attr_value,
UINT16  attr_value_length 
)

To update the value of an attribute in an SDP Database Record.

Description:
This API updates the attribute value of a SDP Service Record, as identified by the given record handle. The new attribute value overwrites the existing memory that holds the current attribute value for the given attribute identifier in the specified SDP Database Record. This API can only be used in cases where some fixed octets of an existing attribute value needs to be changed and the size (in octets) of the new attribute value is not more than the existing attribute value size.
Parameters
[in]record_handleIdentifies the SDP Database Service Record.
[in]attr_idThe Attribute ID whose value to be changed.
[in]attr_valueCaller allocated UCHAR buffer containing the octets of the new value for the specified attribute.
[in]attr_value_lengthSize, in octets, of the buffer containing the new value.
Returns
API_SUCCESS or one of the error codes as defined in BT_error.h.
