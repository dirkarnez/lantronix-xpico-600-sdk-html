Detailed Description

This section describes the EtherMind Hands Free Profile Audio Gateway APIs.

Macro Definition Documentation

◆ BT_hfp_ag_connect

#define BT_hfp_ag_connect (   sc,
  bd_addr 
)    BT_hfp_ag_instance_connect(0x00, (sc), (bd_addr))

To establish connection with remote HFP Unit.

Description:
This API establishes service level connection between AG and a HFP Unit
Parameters
[in]server_channelThe server channel in which connection has to be initiated.
[in]bd_addrBD_ADDR of HFP Unit with whom connection need to be established.
Returns
API_SUCCESS: Indicates connection procedure initiated successfully HFP_AG_ERR_INVALID_STATE: Profile is not started or already connected. HFP_AG_ERR_MUTEX_LOCK_FAILED: Failed to Lock HFP AG Mutex. HFP_AG_ERR_MUTEX_UNLOCK_FAILED: Failed to Unlock HFP AG Mutex. Relevant error code from RFCOMM if any RFCOMM operation failed.
Note
Result of the connection setup procedure completion will be indicated through application callback.

#define BT_hfp_ag_disconnect (   bd_addr)    bt_hfp_ag_device_instance_disconnect((0x00), (bd_addr))

To disconnect from remote HFP Unit.

Description:
This API disconnects existing service level connection with the HFP Unit.
Parameters
[in]bd_addrRemote Device address.
Returns
API_SUCCESS: Indicates disconnection procedure initiated successfully. HFP_AG_ERR_NULL_PARAMETER: Indicates BD_ADDR is NULL. HFP_AG_ERR_INVALID_STATE: Profile is not started or not connected. HFP_AG_ERR_MUTEX_LOCK_FAILED: Failed to Lock HFP AG Mutex. HFP_AG_ERR_MUTEX_UNLOCK_FAILED: Failed to Unlock HFP AG Mutex. HFP_AG_ERR_INVALID_PARAMETER: Failed to disconnect, wrong BD_ADDR is provided. Relevant error code from RFCOMM if any RFCOMM operation failed.
Note
Result of the disconnection procedure completion will be indicated through application callback

◆ BT_hfp_ag_send_data

#define BT_hfp_ag_send_data (   rc,
  rcl 
)    BT_hfp_ag_instance_send_data(0x00, (rc), (rcl))

To send Data/Response/Result Code to HFP Unit.

Description:
This API allows the application to send result code strings to currently connected HFP Unit.
Parameters
[in]result_codeContains information of the HDP Event Notification Callback which HDP should use to report HDP events, the control channel PSM on which HDP must receive control channel connection requests, the L2CAP configuration parameters to be used during control channel connection, and the data channel PSM on which data channel connection shall by HDP be accepted.
[in]result_code_lengthContains information of the HDP Event Notification Callback which HDP should use to report HDP events, the control channel PSM on which HDP must receive control channel connection requests, the L2CAP configuration parameters to be used during control channel connection, and the data channel PSM on which data channel connection shall by HDP be accepted.
Returns
API_SUCCESS or one of the error codes as defined in BLE_ERROR_CODES.
Note
The mep_id is the output parameter; the application shall store this mep_id for initiating HDP control channel establishment procedures.

◆ BT_hfp_ag_start

#define BT_hfp_ag_start (   sc)    BT_hfp_ag_instance_start((NULL), (sc))

To start HFP Audio Gateway.

Description:
This API will switch on HFP AG function on the local device (i.e.) enable AG to listen to peer (HFPU) initiated connections on a RFCOMM channel and enables application to use the services of HFP AG profile.
Parameters
[in]server_channelThe RFCOMM server channel in which the HFP AG will be listening for peer initiated connection.
Returns
API_SUCCESS or one of the error codes as defined in BLE_ERROR_CODES.
