Detailed Description

Parameter structure of elliptic curve of the form, y^2 = x^3 + a*x + b modulo prime p. Each curve parameter is stored as a Big-endian octet string with exact byte length specified. For a small parameter, padding zero(s) is placed in the beginning of the octet string. This structure contains InputBuffers for the octet strings and the lengths.

uint32_t mcuxClEcc_DomainParam_t::misc

[in] packed lengths, via mcuxClEcc_DomainParam_misc_Pack: bits 0~ 7: byteLenP: length of the octet string of curve parameters a, b and p, and x and y coordinates of base point G; bits 8~15: byteLenN: length of the octet string of curve parameter n; bits 16~31: reserved.
