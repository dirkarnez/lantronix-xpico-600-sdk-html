◆ flag

UCHAR BNEP_SETUP::flag

Flag to indicate what action needs to be taken. Flag is valid only when the Event Type is 'BNEP_SETUP_IND'.

0x00 - BNEP 'Setup' accepted automatically 0x01 - Response pending. Call BT_bnep_setup_rsp() API.
