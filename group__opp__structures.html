◆ OPP_CONNECT_STRUCT

typedef struct _OPP_CONNECT_STRUCT OPP_CONNECT_STRUCT

Data type to specify the OPP connect request or connect response parameters.

Description:
This structure contains connect parameters filled by the application or the profile depending on connection request or connection response.

At OPP client side, this structure is filled by the application to send the connect request & filled by the profile to notify the application with the connect response. At OPP server side, this structure is filled by the profile to notify the application of the connect request and the application to send the connect response.

Note
OPP OBEX connection over L2CAP is defined in OPPv1.2 or later specification. To have OPP OBEX connection over L2CAP support, enable OBEX_OVER_L2CAP feature flag in BT_features.h.

◆ OPP_HEADER_STRUCT

typedef struct _OPP_HEADER_STRUCT OPP_HEADER_STRUCT

Data type to specify the information used while calling different APIs.

Description:
This structure contains the pointer to a buffer of UCHAR and the length of the buffer. This structure is filled by the application and given to the profile in various API's.

◆ OPP_HEADERS

typedef union _OPP_HEADERS OPP_HEADERS

Data type to specify the OPP header information.

Description:
Structure to specify the information related to connect request, connect response, other requests and responses both for the OPP client and server.

Depending upon the request/ response, the corresponding structure in this Union to be used.

◆ OPP_REQUEST_STRUCT

typedef struct _OPP_REQUEST_STRUCT OPP_REQUEST_STRUCT

Data type to specify the OPP request parameters.

Description:
This structure contains the request parameters filled by the application or the profile depending on the role.

At OPP client, this structure shall be filled by the application when a request has to be sent to the peer side and at the OPP server, this will be filled by the profile to notify the application of the request received.

◆ OPP_RESPONSE_STRUCT

typedef struct _OPP_RESPONSE_STRUCT OPP_RESPONSE_STRUCT

Data type to specify the OPP response parameters.

Description:
This structure contains the response parameters filled by the application or the profile depending on the role.

At OPP server, this structure shall be filled by the application to send the response for the recently received request and at OPP client, this structure will be filled by the profile to notify the application of the response indication for the previously sent request.
