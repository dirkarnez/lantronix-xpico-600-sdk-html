Detailed Description

Data type to specify the FTP connect request or connect response parameters.

Description:
This structure contains connect parameters filled by the application or the profile depending on connection request or connection response.

At FTP client side, this structure is filled by the application to send the connect request & filled by the profile to notify the application with the connect response. At FTP server side, this structure is filled by the profile to notify the application of the connect request and the application to send the connect response.

Note
FTP OBEX connection over L2CAP is defined in FTPv1.2 or later specification. To have FTP OBEX connection over L2CAP support, enable OBEX_OVER_L2CAP feature flag.
