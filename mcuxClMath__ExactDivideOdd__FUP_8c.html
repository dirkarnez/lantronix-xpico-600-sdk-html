[DESIGN] Suppose T (-Y)^(-1) (mod 2^(bit)). Since (T*Y+1) 0 (mod 2^(bit)), so (T*Y+1)^2 = ((T*Y+2)*T*Y + 1) 0 (mod 2^(2*bit)). This FUP program calculates: T := (T*Y+2)*T (-Y)^(-1) (mod 2^(2*bit)).

[DESIGN] In iteration i (i = 0 ~ rPkcWord-1), this FUP program calculates R[i], and X{i+1} = (Xi + R[i]*Y) / W = (X0 + R[i~0]*Y) / W^(i+1).

CAUTION: The MACCR in this FUP program will access to t+1 PKC words of X, where t = min(yPkcWord, rPkcWord - i) = effectivePkcByteLenY / MCUXCLPKC_WORDSIZE. In the boundary case, t = 1 (when xPkcByteLen = yPkcByteLen = MCUXCLPKC_WORDSIZE), and 2 PKC words of X will be read (but xPkcByteLen = MCUXCLPKC_WORDSIZE).
