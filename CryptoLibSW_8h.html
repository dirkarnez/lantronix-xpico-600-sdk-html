Compute ECDH Diffie Hellman shared secret.

Internal API calling legacy unaccelerated lib (no DSP extension)

Parameters
[in]pPrivateKeyOwn ECP256R1 private key (scalar) to be multiplied with peer's public key, results from previous key pair generation.
[in]pPeerPublicKeypointer on ECP256R1 public key received from peer.
[out]pOutDhKeypointer on buffer to receive DH shared secret.
[in]pMultiplicationBufferpointer on work buffer for multiplication buffer.
Returns
gSecEcdhSuccess_c if success. Note: Does not retry if private key is not suitable
