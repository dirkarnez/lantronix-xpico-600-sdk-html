Exit a CL API function.

This macro is the implementation macro of MCUXCLSESSION_EXIT, with more than 5 arguments. It checks the DI value against the reference value, and exits with Fault Attack if there is a mismatch. It checks the FP value, and exits with Fault Attack if there is a mismatch.
