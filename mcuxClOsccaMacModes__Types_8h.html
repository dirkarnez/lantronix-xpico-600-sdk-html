typedef struct mcuxClOsccaMacModes_AlgorithmDescriptor mcuxClOsccaMacModes_AlgorithmDescriptor_t

Mac Mode structure.

Internal structures / types This internal structure provides all implementation details for a SM4-based mode to the top level mcuxClOsccaMacMode functions. It consists of Init, Update, Finalize and Oneshot engines and the output size.
