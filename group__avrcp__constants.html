#define AVRCP_SET_STATE_FLAG_RELEASED(op_id)   ((op_id) |= AVRCP_STATE_FLAG_RELEASED)
 
#define AVRCP_GET_OPERATION_ID(op_id)   ((op_id) & (~AVRCP_STATE_FLAG_RELEASED))
 
#define AVRCP_GET_STATE_FLAG(op_id)   ((op_id) & AVRCP_STATE_FLAG_RELEASED)

Macro Definition Documentation

◆ AVRCP_GET_STATE_FLAG

#define AVRCP_GET_STATE_FLAG (   op_id)    ((op_id) & AVRCP_STATE_FLAG_RELEASED)

Macro to Extract the State Flag The Macro would result in 'AVRCP_STATE_FLAG_RELEASED' value if the State Flag indicates 'Released', else it would result in 'AVRCP_STATE_FLAG_PRESSED'
