◆ write_task_bt_shutdown()

API_RESULT write_task_bt_shutdown ( void  )

To shutdown Write Task.

Description
This function sets the state of Write Task to shutdown state.

This halts Write Task from servicing the queued elements. However, the task itself is not terminated but brought to a state where it can start functioning once it is signalled. As part of this, the queues which holds the bottom halves are reset.

Parameters
None
Returns
API_SUCCESS or one of the error codes as defined in BLE_ERROR_CODES.
