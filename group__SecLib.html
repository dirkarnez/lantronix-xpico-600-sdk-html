uint32_t  inputLen,

const uint8_t *  pKey,
uint8_t *  pOutput 
)

This function performs AES-128-CBC decryption on a message block.

Parameters
[in]pInputPointer to the location of the input ciphered message.
[in]inputLenInput message length in bytes - must be a multiple of AES_BLOCK_SIZE.
[in,out]pInitVectorPointer to the location of the 128-bit initialization vector. On exit the IV content is updated with ciphered output to be injected as next block IV. Because IV is modifiable, it cannot be RO (const).
[in]pKeyPointer to the location of the 128-bit key.
[out]pOutputPointer to the location to store the plain text output.
Returns
: gSecSuccess_c if no error, gSecBadArgument_c in case of bad arguments, gSecError_c in case of internal error.

◆ AES_128_CBC_Encrypt_And_Pad()

uint32_t AES_128_CBC_Encrypt_And_Pad ( uint8_t *  pInput,
uint32_t  inputLen,
uint8_t *  pInitVector,
const uint8_t *  pKey,
uint8_t *  pOutput 
)

This function performs AES-128-CBC encryption on a message block after padding until AES block completion.

Padding scheme is ISO/IEC 7816-4: one 80h byte (1 bit), followed by as many 00h as required to fill a 128 bit block. Note that if the message length is a multiple of AES block size already, another block is appended to the original message.

Parameters
[in]pInputPointer to the location of the input plain text message.
[in]inputLenInput message length in bytes - no specific constraint.

IMPORTANT: User must make sure output buffer has at least inputLen + 16 bytes size. This constraint does not apply to input buffer (any longer).

Parameters
[in,out]pInitVectorPointer to the location of the 128-bit initialization vector. On exit the IV content is updated with ciphered output to be injected as next block IV. Because it is modifiable it cannot be RO (const).
[in]pKeyPointer to the location of the 128-bit key.
[out]pOutputPointer to the location to store the ciphered output.
Returns
value size of output message after padding is appended.
